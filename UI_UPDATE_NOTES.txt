FarmWise comparison UI update

Changes:
1. Compare Seeds now always highlights the highest rule-based relative-fit score as the green "Priority Pick for Your Farm" when a saved farm profile is available.
2. Small score gaps or demonstration seed records no longer show "No single clear winner". The selected first option is labeled as the first option to review, with a short caution to verify seed details and price.
3. The selected variety's table column is highlighted in green and marked "PRIORITY PICK".
4. Removed the duplicate long Best Choice explanation card. The short explanation now appears inside the priority banner; the comparison table and trade-offs remain available below.
5. The score is still a relative rule-based match, not a probability of success or a yield guarantee.

Validation:
- The earlier backend package run reported BUILD SUCCESS and 4 passing tests before this update.
- This update changes backend comparison ranking wording/selection behavior and frontend JSX. Re-run Maven package and `npm run build` after extracting this ZIP to verify the updated files in your environment.
